# Nudge — MVP Project

## Concept
**Nudge** — gentle reminder app: "partner forgot to call dentist — send one-tap anonymous reminder"

**Core insight:** People avoid reminding important things because they don't want to seem nagging. Nudge bot sends it for you.

**Pain:** "Need partner to do something important — afraid to remind them"

**MVP:**
- Telegram bot: `/nudge @partner do the thing`
- Partner receives anonymous message
- Simple, frictionless, zero-account

**Revenue:** Freemium ($5/mo premium templates + scheduling)

**Stack:** Python + Telegram Bot API (no backend needed for MVP)
